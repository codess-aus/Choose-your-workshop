# Choose your workshop

Pick the hands-on workshop that matches what you want to learn. Each workshop opens on its own site or GitHub repository.

## [Agentic Workflows Workshop](https://copilot-dev-days.github.io/agentic-workflows-workshop/)

Build and deploy agentic workflows with `gh aw`. Automate daily digests, turn Hacker News stories into GitHub issues, and set up a ChatOps slash command—all from the command line.

## [GitHub Copilot CLI for Beginners](https://awesome-copilot.github.com/learning-hub/cli-for-beginners/)

New to Copilot in the terminal? Learn how to use AI-powered command-line assistance in your everyday development workflow.

## [GitHub Copilot CLI Deep Dive Workshop](https://copilot-dev-days.github.io/copilot-cli-deep-dive-workshop/)

Go from installation to advanced automation with hands-on exercises in operating modes, custom instructions, MCP servers, agent skills, plugins, custom agents, hooks, and context management.

## [GitHub Copilot for Non-Developers](https://copilot-dev-days.github.io/copilot-for-non-developers/)

No terminal experience needed. Product and project managers, business process managers, and anyone getting work done can use plain English with Copilot CLI to triage email, pull decisions from meetings, and analyze data.

## [GitHub Copilot at Scale: Interactive Lab for Enterprise Admins](https://github.com/octodemo/copilot-governance-at-scale/tree/main)

Use an interactive canvas in the GitHub Copilot app to explore access, models and features, cost control, agent governance, context, and observability. Connect your enterprise's needs to configuration guidance and try approved exercises in a sandbox.

Leave with a Governance Summary of your choices, observations, and open questions. It’s a starting point for rollout planning, not an audit or authorization to change production settings.
